# G7_Deepfakes_Leitner

Quizz mit Individuellem Text der im Inspector angezeigt wird mit auswahl der richtigen Antwort möglichkeit. Folgende Antwortmöglichkeiten werden im Spiel zufällig aufgelistet. Man hat Pro Quizz nur ein Leben also man kann einmal Falsch beantworten. Beim zweiten mal wird man nicht mehr belohnt und das Quizz qird abgebrochen. Man bekommt immer eine kurze Mitteilung über seine Antwort (Richtig/Falsch durch Grün/Rot) dargestellt. Außerdem ladet die Szene immer automatisch nach dem Video und man kann die nächsten Szenen bestimmen.
